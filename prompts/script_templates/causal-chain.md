# Pattern: Causal Chain

Structure the story as a chain of small failures, each one setting up the next —
the "Swiss cheese model" of disaster: no single mistake sinks a ship, but several
holes lining up do.

Structure:
1. **Hook** (0-30s) — state the outcome's scale, then ask/imply the real question:
   not "what happened" but "how did this many small mistakes line up?"
2. **Link 1 → Link 2 → Link 3...** — walk through each contributing failure (a design
   shortcut, a skipped inspection, a miscommunication, a regulatory gap) explicitly as
   cause leading to the next effect. Name each link so the audience can track the
   chain (works well as its own payoff node: "and that decision would prove fatal
   three hours later").
3. **The break point** — the single moment the chain became unstoppable.
4. **Aftermath/legacy** — which links, if any, got fixed afterward; which didn't
   (and why that matters for the angle you were given).

Keep cause-and-effect language explicit ("because of X, Y happened, which meant Z")
so the mechanism of the disaster — not just its drama — is the throughline.

# Pattern: Mystery First

Open with an unresolved anomaly — a strange detail, an unanswered question, or a
piece of wreckage/evidence that doesn't make sense — BEFORE revealing what ship or
event this even is. Withhold the "why" and let it pull the viewer through the story.

Structure:
1. **Hook** (0-30s) — present the anomaly/mystery directly: an odd fact, a
   contradiction, a detail investigators couldn't initially explain. Do not name the
   ship/event yet if you can help it — tease it.
2. **The reveal of context** — now introduce the ship, the people, the setting;
   frame everything so far as clues to the mystery just raised.
3. **Backward build** — trace the timeline that leads to the anomaly, letting each
   new fact reframe the mystery (each reframe is a natural payoff node).
4. **Resolution** — answer the mystery raised in the hook, using the verified facts.
5. **Legacy** — what the resolved mystery reveals about the angle you were given.

The test for this pattern: could you delete the ship's name from the first 30 seconds
and still have a compelling hook? If yes, you're doing it right.

# Branding assets

Drop the following files here manually (not generated by the pipeline):

- `intro.mp4` -- 3-5s static/animated channel intro. If absent, the assembler
  synthesizes a plain title card so rendering never blocks.
- `outro.mp4` -- 3-5s subscribe/end card. If absent, a plain synthesized end card is used.
- `caption.ttf` -- licensed-for-distribution font (e.g. Open Sans, Noto Sans) used for
  burned-in captions and thumbnail text. If absent, Pillow's bundled default font is used.

## Licensing

Only use assets you have redistribution rights for. Do not use commercial/branded fonts
or copyrighted intro music without a license -- this repo does not audit these files.
